# Phase 09 — scenarios.md 매핑 및 최종 검증 (compact)

## 요구사항
`scenarios.md`의 각 Gherkin 시나리오가 어느 자동화 테스트로 커버되는지, 혹은 왜 진행자 앱 테스트
대상이 아닌지(서버 강제/관리자 전용)를 명시적으로 매핑.

## 왜 이렇게 했는가
- Feature 2-c(트랙 교체 자동전환)는 계약상 트랙 삭제와 동일 처리되어 별도 테스트 없이
  `main_track_test`의 강제종료(trackDeleted) 케이스로 커버 — 자동전환 자체는 [[00_overview]]에서
  이슈 #30으로 분리.
- 서버 강제(403)나 UI에 접근 경로 자체가 없는 시나리오(세션 스코프 위반, 타 트랙 접근 등)는
  의도적으로 테스트 대상에서 제외 — 프론트 테스트로 검증할 대상 자체가 없음.
