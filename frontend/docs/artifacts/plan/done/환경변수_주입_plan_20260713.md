# 앱 전역 네트워크 설정 환경변수 주입 (compact)

## 요구사항
`api_client.dart`/`sse_client.dart`의 API base URL, HTTP 타임아웃, SSE 하트비트 타임아웃이
하드코딩돼 있어 스테이징/프로덕션마다 다른 값을 쓰려면 소스 수정 후 재빌드해야 함. 컴파일 타임
주입으로 전환하되, 인자 없이 실행 시 기존 값과 동일하게 유지(하위 호환).

## 왜 이렇게 했는가
- Flutter는 런타임에 OS 환경변수를 직접 못 읽음(모바일/웹 샌드박스 제약) — `--dart-define`
  계열의 컴파일 타임 주입이 표준 방식이라 채택. 새 의존성 없이 Dart SDK 내장
  `String.fromEnvironment`/`int.fromEnvironment`만 사용.
- CI/배포 파이프라인에서의 실제 시크릿 관리는 범위 밖 — 프론트 배포 파이프라인 자체가 아직 없음.
  `env/dev.json`은 로컬 개발용 템플릿(커밋 대상, 시크릿 아님).
