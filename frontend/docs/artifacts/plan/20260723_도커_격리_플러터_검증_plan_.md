## 검증 체크리스트

- [x] `make -n docker-build`가 `Dockerfile.flutter`만 컨텍스트로 사용해 `cornermon-flutter:3.44.7`을 빌드한다.
- [x] `make -n docker-check`가 bind mount 없이 `docker create`, `docker cp`, `docker start`, `docker rm` 순서를 출력한다.
- [x] 복사 원본에서 `.dart_tool/`, `build/`, `.git/`을 제외한다.
- [x] POSIX 정리 트랩이 짧은 컨테이너 실행 뒤 임시 컨테이너를 삭제함을 확인했다.
- [x] 기존 `run-admin`, `run-facilitator` 타깃이 변경되지 않는다.
- [ ] `make docker-build`로 베이스 이미지를 내려받아 처음부터 이미지를 다시 생성하는 검증 — 현재 커스텀 이미지가 있으므로 실행하지 않았다.
- [ ] `make docker-check`의 전체 `flutter analyze`·`flutter test` 완료 — 패키지 설치가 진행 중인 상태에서 중단했으므로 별도 실행이 필요하다.
