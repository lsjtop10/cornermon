# 캠프 생성 시 기간(startAt/endAt) 필수화 (compact)

## 요구사항
`POST /camps`가 `name`만 받고 `startAt`/`endAt`이 없어, `camps.start_at`이 `NOT NULL`인 DB
제약에 걸려 `23502` 에러로 INSERT가 실패하던 버그. 두 필드를 필수로 받고 검증.

## 왜 이렇게 했는가
- 생성 시점 불변식을 기존 `UpdateSettings`와 별도인 `domain.NewCamp` 생성자로 캡슐화 — 이름/기간
  검증 규칙은 `UpdateSettings`와 동일하게 유지해 로직 중복을 최소화, 신규 에러 타입 없이 기존
  `ErrCampInvalidSettings` sentinel 재사용.
- `CreateCampRequest`에 필수 필드 신설은 breaking change라 `workflow/Collaborate.md` 프로토콜에
  따라 프론트 합의 후 반영.
- `domain.NewCamp` 검증을 트랜잭션 진입 **전**에 끝냄 — 불필요한 tx/rollback 방지.
